## 5. Limitations

- Detection is pattern based: a paraphrased or translated instruction can get past it. That is why it is not the only control: the contract agent has no write tools, approvals are enforced in code by the approval/procurement layer, protected facts (certification, caps, approval rules) can only come from specific document types, and scopes are filtered before retrieval.
- Removing a whole sentence can occasionally remove legitimate text next to an attack.
